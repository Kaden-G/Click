# Click

A personal learning feed: idea cards, narrated Scene Script clips, spaced review, and a five-minute AI interview. Learning design follows *Make It Stick* (Brown, Roediger & McDaniel, 2014). See README.md for layout and spec/scene-script.md for the clip format.

## Change loop

1. Edit content in `content/*.json`, clips in `clips/*.json`, or the app in `src/index.html`. Never edit `dist/index.html` by hand.
2. `python3 build.py`
3. `node tests/feed.test.js`, `node tests/interview.test.js` and `node tests/clips.test.js`; all must report no errors and no failing clips.
4. Commit, then push to `origin main`. After pushing, regenerate the portable bundle with `python3 tools/bundle.py` if it's needed.
5. Republish `dist/index.html` to the existing artifact (https://claude.ai/artifact/2MVxPh4Q35i8eAhgqKR2XA) rather than creating a new one. It declares the `sample` capability; omit `capabilities` on republish to keep it.

## Content rules

- Cards are written in our own words. No quotes from books beyond a few words.
- Every card ends with a `y` ("Try") line: one concrete action.
- Research claims carry a source. Contested findings get a `flag` on the card; myth-style items carry `strength`: Strong, Moderate, or Weak.
- Don't overstate. If evidence is mixed, the card says so.
- New topic batches go in `content/sets/<id>.json` (`id`, `name`, optional `prompt`, `cards[]` with `id`, `t`, `b`, `y`, optional `cat` and `source`). Each set gets its own chip and interview topic and is interleaved into Mixed. Card keys are `<set-id>-<card-id>`.
- Never commit `content/private/` or `click.config.json`; they hold work material and endpoint settings.
- Figures that change over time (budgets, debt, trust funds) name their source and date on the card.
- Government and politics content sticks to how things work, sourced to official or nonpartisan data, and debunks myths from across the spectrum.

## Clip rules

- One idea per clip, 1 to 8 beats, 4 to 20 seconds each, under 120 seconds total.
- Every clip ends with a `recall` beat.
- No invented numbers. If a `compare` would need made-up heights, use `split`.
- Anything not drawn to scale says so on screen (`note`).
- Clips about research findings set `strength`; the player shows it the whole time.
- The clip `id` matches its filename and, when tied to a card, the card key (`<book-or-set-id>-<n>`), so clip grades feed the review queue.

## Design guardrails

- The model is rented and swappable (Scene Script writing, interview). Value lives in the corpus, the renderer, and review data. Don't add features that only resell a model call.
- Learning features follow the research: generation before reveal, retrieval over rereading, spacing, interleaving, calibration, feedback.
- Keep the page self-contained: CDN allowlist only, theme tokens for every color, works at 400px wide.

# Click

Ideas that click, and stick. A personal learning feed: bite-sized idea cards, short narrated explainer clips, spaced review, and a five-minute AI interview with feedback. The learning design follows *Make It Stick* (Brown, Roediger & McDaniel, 2014).

## Layout

| Path | What it is |
|---|---|
| `src/index.html` | The app: clip renderer, feed, review, interview |
| `content/books.json` | 50 clicks from 10 books (2016–2024) |
| `content/myths.json` | 20 clicks testing 10 common beliefs, each with an evidence-strength rating |
| `clips/*.json` | One Scene Script per clip (29) |
| `spec/scene-script.md` | The Scene Script format and its rules |
| `content/sets/*.json` | Card sets in a simple format (`id`, `name`, `cards[]`); "Things people get wrong" lives here |
| `content/private/` | Your own sets, e.g. generated from product docs. Git-ignored |
| `build.py` | Inlines content and clips into `dist/index.html` |
| `llm.py` | Model adapter: OpenAI-compatible, Azure OpenAI, or Anthropic endpoints |
| `serve.py` | Local server for Click that routes AI calls to your configured model |
| `generate.py` | Turns documentation into study cards with your model |
| `tools/bundle.py` | Packs the repo into `click-bundle.txt` for moving to another machine |
| `tests/` | Headless browser checks for the feed and the interview |

## Build and test

```sh
python3 build.py              # writes dist/index.html
node tests/feed.test.js       # predict, reveal, review, grade, clip recall
node tests/interview.test.js  # offline and simulated-AI interviews
node tests/clips.test.js      # every Scene Script validates and renders
```

Tests need Node and Playwright with Chromium.

## Run it with your work models

Use only models and endpoints your organization has approved, and only put material into Click that you're allowed to send to them.

1. **Unpack** (if you came from `click-bundle.txt`): `python3 click-bundle.txt`, then `cd click`.
2. **Configure the model:** `cp click.config.example.json click.config.json`, then edit it.
   - `provider`: `openai` for any OpenAI-compatible endpoint (most AI gateways, LiteLLM, vLLM), `azure` for Azure OpenAI, `anthropic` for the Anthropic API.
   - `base_url`: for `openai`, the URL ending in `/v1`; for `azure`, the full deployment URL including `?api-version=...`; for `anthropic`, the API host.
   - `model`: the model name your gateway expects.
   - `api_key_env`: the environment variable that holds your key. Leave it empty if your gateway needs no key.
   - `extra_headers`: any headers your gateway requires.
   - `ca_bundle`: path to your company's certificate bundle if HTTPS fails with a certificate error.
   - Newer OpenAI models may need `"max_tokens_field": "max_completion_tokens"`.
3. **Set your key** for this Terminal session: `export CLICK_API_KEY=...`
4. **Make cards from your product docs** (Markdown, text or HTML):
   `python3 generate.py --set myproduct --name "My Product" path/to/docs/*.md`
   Cards are written to `content/private/myproduct.json`. Read through them and delete or fix any that are wrong; the model only drafts them.
5. **Build and run:** `python3 build.py`, then `python3 serve.py --open`.
6. Your set appears as its own chip in the feed and as an interview topic. The interview runs on your configured model.

Opening `dist/index.html` directly also works, but without AI: the interview falls back to offline mode.

**Keep work content out of personal accounts.** `content/private/` and `click.config.json` are git-ignored. Don't copy generated sets back to a personal machine or repo.

## Where the value lives

The model is rented and swappable: it writes Scene Scripts and runs the interview. The corpus (`content/`, `clips/`), the renderer, and your review history are what Click owns.

## Known limits

- Review progress lives in browser storage, per device. Moving it to SQLite is the next infrastructure step.
- Interview questions are generated up front; there are no adaptive follow-ups yet.
- Reflection, the one *Make It Stick* principle not yet covered, is planned as a weekly prompt.

#!/usr/bin/env python3
"""Build dist/index.html: inline content/ and clips/ JSON into src/index.html.

The published artifact is dist/index.html. Edit content and clips as JSON,
edit the app in src/index.html, then run: python3 build.py
"""
import json, pathlib, sys

ROOT = pathlib.Path(__file__).parent
REQUIRED_CLIP = {"id", "title", "beats"}


def load(p):
    return json.loads((ROOT / p).read_text(encoding="utf-8"))


def js(value):
    # Safe to inline inside a <script> element.
    return json.dumps(value, ensure_ascii=False).replace("</", "<\\/")


def main():
    books, myths = load("content/books.json"), load("content/myths.json")
    sets, set_ids = [], {b["id"] for b in books} | {"myth"}
    for folder in ("content/private", "content/sets"):
        for f in sorted((ROOT / folder).glob("*.json")):
            s = json.loads(f.read_text(encoding="utf-8"))
            if not s.get("id") or not s.get("name") or not isinstance(s.get("cards"), list):
                sys.exit(f"{f}: a set needs id, name and a cards list")
            if s["id"] in set_ids:
                sys.exit(f"{f}: set id {s['id']!r} is already used")
            set_ids.add(s["id"])
            card_ids = set()
            for c in s["cards"]:
                if not all(isinstance(c.get(k), str) and c[k] for k in ("id", "t", "b", "y")):
                    sys.exit(f"{f}: every card needs id, t, b and y")
                if c["id"] in card_ids:
                    sys.exit(f"{f}: duplicate card id {c['id']!r}")
                card_ids.add(c["id"])
            sets.append(s)
    clips = {}
    for f in sorted((ROOT / "clips").glob("*.json")):
        c = json.loads(f.read_text(encoding="utf-8"))
        missing = REQUIRED_CLIP - c.keys()
        if missing:
            sys.exit(f"{f.name}: missing {sorted(missing)}")
        if c["id"] != f.stem:
            sys.exit(f"{f.name}: id is {c['id']!r}, expected {f.stem!r}")
        clips[c["id"]] = c
    example = clips.pop("spaced-repetition-101")
    html = (ROOT / "src/index.html").read_text(encoding="utf-8")
    for token, value in {
        "/*@EXAMPLE*/null": example, "/*@CLIPS*/{}": clips,
        "/*@MYTHS*/[]": myths, "/*@SETS*/[]": sets, "/*@BOOKS*/[]": books,
    }.items():
        if html.count(token) != 1:
            sys.exit(f"src/index.html: expected one {token}")
        html = html.replace(token, js(value))
    (ROOT / "dist").mkdir(exist_ok=True)
    (ROOT / "dist/index.html").write_text(html, encoding="utf-8")
    cards = sum(len(b["clicks"]) for b in books) + sum(len(m["clicks"]) for m in myths) + sum(len(s["cards"]) for s in sets)
    print(f"dist/index.html: {cards} cards in {len(sets)} sets plus books and myths, {len(clips) + 1} clips")


if __name__ == "__main__":
    main()

never lands in a personal repo. Re-running merges new cards into the set and
keeps existing card ids, so your review history stays attached.
"""
import argparse, html, json, pathlib, re, sys
import llm

ROOT = pathlib.Path(__file__).parent
PROMPT = """You are writing study cards to help an engineer learn a product from its own documentation. Use ONLY the text below. Do not add outside facts or guess.

Write up to {n} cards. Each card is one idea worth remembering: how something works, why it's designed that way, a limit or default, a dependency, an interface, or a common mistake. Skip boilerplate, legal text, tables of contents and changelog noise. If nothing here is worth a card, reply [].

Each card is a JSON object:
  "t": a question the learner should be able to answer, under 15 words, that doesn't give the answer away
  "b": the answer in plain words, 40 to 80 words, specific to this product
  "y": one concrete action to apply or check it, under 20 words
  "cat": a short topic label, 1 to 3 words

Reply with only a JSON array of cards.

SOURCE: {source}
TEXT:
{text}"""


def read_text(path):
    raw = path.read_text(encoding="utf-8", errors="replace")
    if path.suffix.lower() in (".html", ".htm"):
        raw = re.sub(r"(?is)<(script|style).*?</\1>", " ", raw)
        raw = html.unescape(re.sub(r"<[^>]+>", " ", raw))
    return re.sub(r"[ \t]+", " ", raw)


def chunks(text, limit):
    heading, buf, out = "", [], []
    for para in re.split(r"\n\s*\n", text):
        h = re.match(r"\s*#{1,4}\s+(.+)", para)
        if h:
            heading = h.group(1).strip()[:80]
        if buf and sum(len(p) for p in buf) + len(para) > limit:
            out.append(("\n\n".join(buf), heading))
            buf = []
        buf.append(para[:limit])
    if buf:
        out.append(("\n\n".join(buf), heading))
    return out


def slug(s):
    return re.sub(r"[^a-z0-9]+", "-", s.lower()).strip("-")[:40] or "card"


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--set", required=True, help="short id, e.g. acme (letters, numbers, hyphens)")
    ap.add_argument("--name", required=True, help="name shown in the feed, e.g. 'Acme Platform'")
    ap.add_argument("--per-chunk", type=int, default=5)
    ap.add_argument("--chunk-chars", type=int, default=6000)
    ap.add_argument("files", nargs="+")
    a = ap.parse_args()
    if not re.fullmatch(r"[a-z0-9][a-z0-9-]{0,30}", a.set):
        sys.exit("--set must be lowercase letters, numbers and hyphens.")
    cfg = llm.load_config()
    out = ROOT / "content/private" / f"{a.set}.json"
    out.parent.mkdir(parents=True, exist_ok=True)
    data = json.loads(out.read_text()) if out.exists() else {"id": a.set, "name": a.name, "cards": []}
    data["name"] = a.name
    seen = {c["t"].strip().lower() for c in data["cards"]}
    ids = {c["id"] for c in data["cards"]}
    added = 0
    for f in a.files:
        path = pathlib.Path(f)
        if not path.is_file():
            print(f"skip {f}: not a file"); continue
        for i, (text, heading) in enumerate(chunks(read_text(path), a.chunk_chars)):
            source = path.name + (f" · {heading}" if heading else "")
            try:
                cards = llm.parse_json(llm.complete(PROMPT.format(n=a.per_chunk, source=source, text=text), cfg))
            except llm.LLMError as e:
                print(f"  {source}: {e}"); continue
            for c in cards if isinstance(cards, list) else []:
                if not all(isinstance(c.get(k), str) and c[k].strip() for k in ("t", "b", "y")):
                    continue
                if c["t"].strip().lower() in seen:
                    continue
                cid, n = slug(c["t"]), 2
                while cid in ids:
                    cid, n = f"{slug(c['t'])}-{n}", n + 1
                ids.add(cid); seen.add(c["t"].strip().lower())
                data["cards"].append({"id": cid, "cat": str(c.get("cat", "")).strip()[:40], "source": source,
                                      "t": c["t"].strip(), "b": c["b"].strip(), "y": c["y"].strip()})
                added += 1
            print(f"  {source}: {len(data['cards'])} cards so far")
    out.write_text(json.dumps(data, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
    print(f"Added {added} cards to {out.relative_to(ROOT)} ({len(data['cards'])} total). Now run: python3 build.py")


if __name__ == "__main__":
    main()


===== FILE: llm.py =====
"""Model adapter shared by serve.py and generate.py.

Reads click.config.json and sends one prompt to the configured endpoint.
Supported providers:
  openai     Any OpenAI-compatible /chat/completions endpoint (OpenAI, LiteLLM,
             vLLM, most enterprise AI gateways).
  azure      Azure OpenAI: base_url is the full deployment URL, including
             ?api-version=..., and the key goes in the api-key header.
  anthropic  Anthropic Messages API (/v1/messages).
Uses only the Python standard library.
"""
import json, os, pathlib, ssl, urllib.error, urllib.request

ROOT = pathlib.Path(__file__).parent
CONFIG = ROOT / "click.config.json"


class LLMError(Exception):
    pass


def load_config():
    if not CONFIG.exists():
        raise LLMError("No click.config.json. Copy click.config.example.json to click.config.json and fill it in.")
    cfg = json.loads(CONFIG.read_text(encoding="utf-8"))
    for key in ("provider", "base_url", "model"):
        if not cfg.get(key):
            raise LLMError(f"click.config.json is missing '{key}'.")
    if cfg["provider"] not in ("openai", "azure", "anthropic"):
        raise LLMError("provider must be openai, azure or anthropic.")
    return cfg


def _key(cfg):
    env = cfg.get("api_key_env")
    if not env:
        return None
    val = os.environ.get(env)
    if not val:
        raise LLMError(f"Environment variable {env} is empty. Export your API key first.")
    return val


def complete(prompt, cfg, max_tokens=None, timeout=None):
    max_tokens = max_tokens or cfg.get("max_tokens", 4000)
    timeout = timeout or cfg.get("timeout_seconds", 180)
    key, p = _key(cfg), cfg["provider"]
    headers = {"Content-Type": "application/json"}
    msgs = [{"role": "user", "content": prompt}]
    if p == "anthropic":
        url = cfg["base_url"].rstrip("/") + "/v1/messages"
        body = {"model": cfg["model"], "max_tokens": max_tokens, "messages": msgs}
        headers["anthropic-version"] = cfg.get("anthropic_version", "2023-06-01")
        if key:
            headers["x-api-key"] = key
    else:
        url = cfg["base_url"] if p == "azure" else cfg["base_url"].rstrip("/") + "/chat/completions"
        body = {"messages": msgs, cfg.get("max_tokens_field", "max_tokens"): max_tokens}
        if p == "openai":
            body["model"] = cfg["model"]
        if key:
            headers["api-key" if p == "azure" else "Authorization"] = key if p == "azure" else "Bearer " + key
    if "temperature" in cfg:
        body["temperature"] = cfg["temperature"]
    headers.update(cfg.get("extra_headers", {}))
    ctx = ssl.create_default_context(cafile=cfg["ca_bundle"]) if cfg.get("ca_bundle") else None
    req = urllib.request.Request(url, data=json.dumps(body).encode(), headers=headers, method="POST")
    try:
        with urllib.request.urlopen(req, timeout=timeout, context=ctx) as r:
            data = json.loads(r.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        raise LLMError(f"{e.code} from model endpoint: {e.read().decode('utf-8', 'replace')[:500]}")
    except (urllib.error.URLError, TimeoutError, ssl.SSLError) as e:
        raise LLMError(f"Couldn't reach the model endpoint: {e}")
    try:
        if p == "anthropic":
            return "".join(b.get("text", "") for b in data["content"] if b.get("type") == "text")
        return data["choices"][0]["message"]["content"]
    except (KeyError, IndexError, TypeError):
        raise LLMError("Unexpected response shape: " + json.dumps(data)[:500])


def parse_json(text):
    """Read a JSON value from a model reply: whole text, a fenced block, or first bracket to last."""
    text = text.strip()
    try:
        return json.loads(text)
    except ValueError:
        pass
    if "```" in text:
        inner = text.split("```")[1]
        inner = inner[inner.find("\n") + 1:] if inner.lstrip().startswith(("json", "JSON")) else inner
        try:
            return json.loads(inner)
        except ValueError:
            pass
    starts = [i for i in (text.find("["), text.find("{")) if i >= 0]
    if starts:
        s = min(starts)
        e = max(text.rfind("]"), text.rfind("}"))
        try:
            return json.loads(text[s:e + 1])
        except ValueError:
            pass
    raise LLMError("The model's reply wasn't valid JSON.")

#!/usr/bin/env python3
"""Serve Click locally and route its AI calls to your configured model.

    python3 serve.py            # http://127.0.0.1:8765
    python3 serve.py --port 9000 --open

Listens on 127.0.0.1 only. Your API key stays in this process; the page never
sees it. Prompts and answers are never logged.
"""
import argparse, json, pathlib, sys, webbrowser
from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer
import llm

ROOT = pathlib.Path(__file__).parent
MAX_BODY = 1_000_000


class Handler(SimpleHTTPRequestHandler):
    cfg = None
    extensions_map = {**SimpleHTTPRequestHandler.extensions_map,
                      ".html": "text/html; charset=utf-8", ".js": "text/javascript; charset=utf-8",
                      ".json": "application/json; charset=utf-8"}

    def __init__(self, *a, **kw):
        super().__init__(*a, directory=str(ROOT / "dist"), **kw)

    def _json(self, code, obj):
        body = json.dumps(obj).encode()
        self.send_response(code)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.path == "/api/health":
            return self._json(200, {"ok": True, "provider": self.cfg["provider"], "model": self.cfg["model"]})
        return super().do_GET()

    def do_POST(self):
        if self.path != "/api/llm":
            return self._json(404, {"error": "Not found"})
        n = int(self.headers.get("Content-Length") or 0)
        if n <= 0 or n > MAX_BODY:
            return self._json(413, {"error": "Request too large", "code": "local_error"})
        try:
            prompt = json.loads(self.rfile.read(n))["prompt"]
            text = llm.complete(str(prompt), self.cfg)
            if not text.strip():
                return self._json(502, {"error": "Empty reply from model", "code": "local_error"})
            return self._json(200, {"text": text})
        except llm.LLMError as e:
            sys.stderr.write(f"[click] model error: {e}\n")
            return self._json(502, {"error": str(e), "code": "local_error"})
        except (ValueError, KeyError):
            return self._json(400, {"error": "Bad request", "code": "local_error"})

    def log_message(self, fmt, *args):
        if "/api/llm" not in (args[0] if args else ""):
            super().log_message(fmt, *args)


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--port", type=int, default=8765)
    ap.add_argument("--open", action="store_true", help="open Click in your browser")
    args = ap.parse_args()
    if not (ROOT / "dist/index.html").exists():
        sys.exit("dist/index.html is missing. Run: python3 build.py")
    try:
        Handler.cfg = llm.load_config()
        llm._key(Handler.cfg)
    except llm.LLMError as e:
        sys.exit(str(e))
    url = f"http://127.0.0.1:{args.port}/"
    print(f"Click running at {url}  (model: {Handler.cfg['model']} via {Handler.cfg['provider']})  Ctrl+C to stop")
    if args.open:
        webbrowser.open(url)
    ThreadingHTTPServer(("127.0.0.1", args.port), Handler).serve_forever()


if __name__ == "__main__":
    main()

# Scene Script v0

A clip is a small JSON file. A model (or a person) writes it; Click's renderer performs it with motion, captions, and an on-device voice. The script supplies numbers and labels; the renderer owns every coordinate, color, and easing curve.

```json
{
  "id": "atomic-1",
  "title": "Tiny gains compound",
  "strength": "Strong",
  "beats": [
    { "primitive": "title", "dur": 5, "say": "Narration and captions.", "data": { "kicker": "Atomic Habits", "lines": ["Tiny gains", "compound"] } }
  ]
}
```

`id` must match the file name. `strength` (`Strong`, `Moderate`, `Weak`) is required for clips about a research finding and stays on screen for the whole clip.

## Primitives

| Primitive | Shows | Data |
|---|---|---|
| `title` | Opening hook | `kicker`, `lines[]` |
| `curve` | A value decaying over days, with resets | `reviews[]` in days, `ghost` |
| `growth` | Compounding, straight lines, and S-curves | `title`, `points`, `series[{label, fn, rate, tone}]`, `note` |
| `intervals` | Bars to scale, revealed in order | `title`, `max`, `unit`, `items[{label, value}]` |
| `compare` | Two or three bars of one measured quantity | `title`, `items[{label, value, tone}]`, `note[]` |
| `split` | Two sides contrasted trait by trait | `title`, `left{label, rows[]}`, `right{label, rows[]}` |
| `grid` | A whole as countable dots | `title`, `total`, `cols`, `filled`, `highlight[]`, `legend[]` |
| `network` | Layered nodes and links, chokepoints lit | `title`, `nodes[{id, label, layer}]`, `links[[a, b]]`, `choke[]` |
| `flow` | A short process, lit step by step | `steps[{t, s}]` |
| `recall` | Pauses for the viewer to answer, then reveals | `question`, `answer` |

## Rules

1. One idea per clip, ending with a `recall` beat.
2. 1 to 8 beats, 4 to 20 seconds each, under 120 seconds total.
3. `say` is both narration and captions, so write it to be heard.
4. Data holds numbers and labels only, never positions.
5. Anything not drawn to scale says so on screen.
6. If you would have to invent the numbers for a `compare`, use `split`.
7. A beat waits for the voice to finish, so long lines stretch the beat.

const esc = s => String(s).replace(/[&<>"]/g, c => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;" }[c]));
const clamp = (v, a = 0, b = 1) => Math.max(a, Math.min(b, v));
const ease = x => 1 - Math.pow(1 - clamp(x), 3);
const reduced = matchMedia("(prefers-reduced-motion: reduce)").matches;
const svg = inner => `<svg viewBox="0 0 360 400" role="img" aria-label="Animated scene">${inner}</svg>`;

function wrapLines(text, max) {
  const out = []; let line = "";
  for (const w of String(text || "").split(/\s+/)) {
    if (line && (line + " " + w).length > max) { out.push(line); line = w; } else line = line ? line + " " + w : w;
  }
  if (line) out.push(line);
  return out;
}

const PRIM = {
  title(d, p) {
    const lines = (d.lines || []).map((l, i) => {
      const q = ease(p * 2.2 - i * 0.25);
      return `<text x="40" y="${205 + i * 42 + (1 - q) * 14}" opacity="${q}" class="disp" font-size="34" font-weight="700" fill="var(--stage-ink)">${esc(l)}</text>`;
    }).join("");
    const k = ease(p * 3);
    const u = ease(p * 1.6 - 0.3);
    const uy = 205 + (d.lines || []).length * 42 - 18;
    return svg(`<text x="40" y="160" opacity="${k}" class="mono" font-size="12" letter-spacing="1.2" fill="var(--mem)">${esc((d.kicker || "").toUpperCase())}</text>${lines}
      <rect x="40" y="${uy}" width="${u * 170}" height="5" rx="2" fill="var(--mem)"/>`);
  },

  curve(d, p) {
    const x0 = 58, x1 = 330, y0 = 70, y1 = 300, days = 30;
    const X = t => x0 + (t / days) * (x1 - x0), Y = m => y1 - m * (y1 - y0);
    const reviews = (d.reviews || []).slice().sort((a, b) => a - b);
    const mem = (t, rs) => { let k = 0, last = 0; for (const r of rs) if (r <= t) { k++; last = r; } return Math.exp(-(t - last) / (1.4 * Math.pow(2.6, k))); };
    const path = (rs, tMax) => { let s = ""; for (let t = 0; t <= tMax + 1e-9; t += 0.1) s += (s ? "L" : "M") + X(t).toFixed(1) + " " + Y(mem(t, rs)).toFixed(1); return s; };
    const tMax = ease(p * 1.15) * days;
    const ticks = [0, 7, 14, 21, 28].map(t => `<text x="${X(t)}" y="320" text-anchor="middle" class="mono" font-size="11" fill="var(--stage-dim)">${t}</text>`).join("");
    const grid = [0.25, 0.5, 0.75, 1].map(m => `<line x1="${x0}" x2="${x1}" y1="${Y(m)}" y2="${Y(m)}" stroke="var(--stage-line)" stroke-width="1"/>`).join("");
    const ghost = d.ghost ? `<path d="${path([], days)}" fill="none" stroke="var(--stage-dim)" stroke-width="1.5" stroke-dasharray="4 5" opacity=".7"/>` : "";
    const marks = reviews.filter(r => r <= tMax).map((r, i) =>
      `<line x1="${X(r)}" x2="${X(r)}" y1="${y0}" y2="${y1}" stroke="var(--rev)" stroke-width="1" opacity=".45"/>
       <circle cx="${X(r)}" cy="${y0}" r="5" fill="var(--rev)"/>
       <text x="${X(r)}" y="${y0 - 12}" text-anchor="middle" class="mono" font-size="11" fill="var(--rev)">R${i + 1}</text>`).join("");
    const head = `<circle cx="${X(tMax)}" cy="${Y(mem(tMax, reviews))}" r="5" fill="var(--mem)"/>`;
    return svg(`<text x="${x0}" y="36" class="mono" font-size="11" fill="var(--stage-dim)">MEMORY</text>

  intervals(d, p) {

      const q = ease(p * (n + 1) * 0.9 - i);

function validate(s) {
  if (!s || !Array.isArray(s.beats)) return "The script needs a beats array.";
  if (s.beats.length < 1 || s.beats.length > 8) return `Use 1 to 8 beats. This script has ${s.beats.length}.`;
  let total = 0;
  for (const [i, b] of s.beats.entries()) {
    const n = i + 1;
    if (!PRIM[b.primitive]) return `Beat ${n} uses "${b.primitive}". Pick one of: ${Object.keys(PRIM).join(", ")}.`;
    if (typeof b.say !== "string" || !b.say.trim()) return `Beat ${n} needs a say line.`;
    if (typeof b.dur !== "number" || b.dur < 4 || b.dur > 20) return `Beat ${n} needs dur between 4 and 20 seconds.`;
    if (b.primitive === "recall" && !(b.data && b.data.question && b.data.answer)) return `Beat ${n} is a recall beat and needs data.question and data.answer.`;
    total += b.dur;
  }
  if (s.strength && !["Strong", "Moderate", "Weak"].includes(s.strength)) return "Set strength to Strong, Moderate or Weak.";
  if (total > 120) return `This script runs ${total} seconds. Trim it under 120.`;
  return null;
}

def main():
    out = pathlib.Path(__file__).resolve().parent / "click"
    if out.exists() and "--force" not in sys.argv:
        sys.exit(f"{out} already exists. Move it, or rerun with --force to overwrite matching files.")
    count = 0
    for block in PAYLOAD.split("\n===== FILE: ")[1:]:
        head, _, body = block.partition("\n")
        rel = head.rstrip(" =")
        path = out / rel
        if ".." in pathlib.PurePosixPath(rel).parts:
            sys.exit(f"Refusing unsafe path: {rel}")
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(body[:-1] if body.endswith("\n") else body, encoding="utf-8")
        count += 1
    print(f"Unpacked {count} files into {out}")
    subprocess.run([sys.executable, "build.py"], cwd=out, check=False)
    print("Next: open README.md and follow 'Run it with your work models'.")
